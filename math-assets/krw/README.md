# 한국 화폐 학습 이미지

`First_Math.html`의 생활수학 → 돈에서 사용하는 한국은행 화폐 이미지입니다.

- 지폐: 1,000원, 5,000원, 10,000원, 50,000원
- 동전: 10원, 50원, 100원, 500원
- 각 금액에 `-front.jpg`(앞면), `-back.jpg`(뒷면)가 있습니다.
- 원본의 ‘보기’ 또는 ‘Specimen’ 표시를 유지했습니다.
- 오프라인 사용이나 다른 기기로 옮길 때 HTML 옆의 `math-assets/krw` 폴더 구조를 유지하세요.

출처: [한국은행 현용 은행권](https://www.bok.or.kr/portal/main/contents.do?menuNo=200017), [한국은행 현용 주화](https://www.bok.or.kr/portal/main/contents.do?menuNo=200367).
개별 이미지의 원본 주소는 `sources.json`에 기록되어 있습니다.
